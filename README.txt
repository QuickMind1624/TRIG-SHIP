S-D-Angle

This version follows the reading-first derivation architecture:
- Four whole-program themes: Blue, Green, Purple, Brown.
- sin() remains blue and cos() remains green in every theme.
- HUMBLE NOTICE opening screen.
- Only sin() and cos() routes.
- Exact symbolic values only; no decimal approximations.
- Every angle is a folder: the value is shown on the row, then the full derivation opens.
- School-style vertical fractions are rendered in the browser.
- Derivations are intentionally uncompressed.
- Important formulas have DERIVE controls that open their own derivation folder.
- The first-web handoff is represented as a placeholder because no real first-web URL was supplied.

Open index.html in a modern desktop or mobile browser.
