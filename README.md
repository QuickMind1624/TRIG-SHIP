# TRIG-FUNCTIONS

Interactive trigonometry learning website built with plain HTML, CSS and JavaScript.

## Project structure

- `index.html` — page structure and sections
- `style.css` — main styling
- `responsive-v2.css` — mobile/responsive styling
- `script.js` — application logic and interactions
- `data/school-values.js` — standard trigonometric values
- `data/other-values.js` — additional trigonometric values
- `data/formulas.js` — formula library data
- `data/pythagoras.js` — Pythagoras teaching module

## Run locally

Open the folder with a local web server. For Python:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000/`.

## GitHub Pages

The repository root must contain `index.html`. Deploy the `main` branch `/ (root)` with GitHub Pages.

## Important

The project intentionally has no framework or build step. Keep file names and folder names exactly as written because web hosting paths are case-sensitive.
