More ways to derive sin(15°)

An additional derivation route attached inside TRIG-SHIP. This route uses the same 30° and 45° exact-angle ingredients, but lays the construction out explicitly.

Unit-circle / construction route
Exact-angle decomposition
01 · START

Write 15° as a difference of two known angles

15° = 45° − 30°

Both 45° and 30° have exact sine and cosine values, so this turns the unknown value into quantities that can be derived exactly.

02 · USE THE SINE DIFFERENCE RELATION

Expand the target angle

sin(45° − 30°) = sin45° cos30° − cos45° sin30°

The subtraction structure produces the minus sign between the two products.

03 · SUBSTITUTE EXACT VALUES

Insert the known special-angle values

= (√2/2)(√3/2) − (√2/2)(1/2)

Nothing is approximated: every ingredient remains exact.

04 · MULTIPLY

Evaluate each product

= √6/4 − √2/4

Both terms already have denominator 4, so they can be combined directly.

05 · COMBINE

Put the terms over one denominator

= (√6 − √2)/4

This is the exact radical form of the value.

06 · RESULT
sin15° = (√6 − √2)/4
